# EA-Hub

EA-Hub is a self-hosted enterprise-architecture hub. It has its own PostgreSQL 16, daily backups, and an admin console.

Fill in **Site address** and **Admin e-mail**. Then turn on **Ingress** and enter a host name, or leave Ingress off to try the app with `kubectl port-forward`. If you leave the admin password empty, one is generated, and the release notes show how to read it.

Guides: https://github.com/E20E-Tools/ea-hub-selfhost/tree/main/docs/en
